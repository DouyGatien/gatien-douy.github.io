# Portfolio – Gatien Douy

Portfolio personnel de Gatien Douy, Développeur Web Fullstack.

🌐 **Voir le portfolio en ligne** : https://gatien-douy.github.io

## Stack
- Next.js / React / TypeScript (frontend)
- Symfony 7 / PHP (backend)
- HTML5 · CSS3 · JavaScript

## Déploiement (GitHub Pages)

1. Créer un repo GitHub nommé exactement `gatien-douy.github.io`
2. Pousser ce dossier à la racine du repo
3. Dans Settings → Pages → Source : sélectionner `main` / `root`
4. Le site sera disponible sur `https://gatien-douy.github.io`
